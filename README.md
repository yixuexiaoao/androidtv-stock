# A股看盘TV（androidtv-stock）

在 Android TV / 电视盒子上看 A 股实时行情。遥控器操作，多画面同屏，局域网 Web 后台设置，到价闪烁提醒。

> 行情来自腾讯、新浪的公开接口，可能有延迟或中断，仅供个人参考，不构成投资建议。本 App 不含任何交易功能。

## 功能

- **遥控器适配**：全部功能可用 D-pad 操作，电视桌面（Leanback）显示入口，也能在手机/平板上运行。
- **多画面**：1/2/3/4/6/8/9/12/16 画面；1大2小、1大3小、1大5小、1大7小、2大4小、2大8小、中心1大12小等监控式不规则分屏；还可以在后台用鼠标画自定义布局。股票多于窗口数时自动分页、可定时轮播。
- **展示方式**：图文、分时图、K线图（日/周/月）、纯文字，可全局设置也可单只设置。可调刷新间隔、字体大小、主题、涨跌颜色、窗口间距等。
- **Web 后台**：打开 App 自动启动。设置监控股票、目标价、下破价、购买价、股数、持仓价、成本价、买入日期、备注、涨跌幅提醒、盈亏提醒等。只填代码也行，默认只监控。
- **到价提醒**：窗口闪烁、全屏闪烁、顶部横幅、声音，可任意组合，全局或单只设置；可调闪烁颜色、速度、持续时间、重复间隔。
- **其他**：大盘指数和持仓汇总状态栏、底部滚动行情、隐私模式（隐藏持仓金额）、防烧屏微移、价格跳动闪烁、配置导入导出、访问密码、开机自启、盘中/盘后不同刷新频率。

- **更新与调试**：App 内检查更新并下载安装；运行日志可在 Web 后台查看、筛选、下载和清除，崩溃也会记录。
- **白天/夜晚主题**：可手动选择，也可按时间自动切换。

## 遥控器按键

| 按键 | 宫格界面 | 放大界面 |
| --- | --- | --- |
| 方向键 | 移动焦点；左右到边缘时翻页；向上到“设置”按钮 | 左右切换股票；上下切换图表/文字 |
| 确认 | 放大当前股票（含五档盘口） | 返回宫格 |
| 长按确认 / 菜单键 | 打开设置 | 打开设置 |
| 频道 +/- | 翻页 | 切换股票 |
| 数字 1/2/3/4/6/8/9 | 切换对应画面数 | - |
| 数字 0 | 循环切换展示方式 | - |
| 信息键 | 显示后台二维码 | 显示后台二维码 |
| 返回 | 连按两次退出 | 返回宫格 |

有提醒时按**确认或返回键**关闭提醒。

## Web 后台

打开 App 后，顶部状态栏会显示后台地址（如 `192.168.1.10:8080`），在同一局域网的手机或电脑浏览器中打开即可，也可以在“设置 → Web 后台”中扫码。

- 默认无密码。局域网内其他人也能访问，**建议在“系统”页设置访问密码**，尤其是填写了持仓时。
- 服务走明文 HTTP，密码和持仓在局域网内不加密，请勿把端口映射到公网。
- 默认端口 8080，被占用时自动尝试后面 9 个端口。

## 安装

在仓库 [Releases](../../releases) 页面下载对应的 APK：

| 文件 | 适用设备 |
| --- | --- |
| `*-armeabi-v7a-release.apk` | v7（32 位）电视/盒子 |
| `*-arm64-v8a-release.apk` | v8（64 位）电视/盒子 |
| `*-universal-release.apk` | 不确定架构时使用 |

最低支持 Android 5.0。

## 版本发布

- 每次推送到 `main`：自动发布预发布版 `v<VERSION>-pre.<运行序号>`，标记为 Pre-release。
- 推送标签 `v<VERSION>`（必须与 `VERSION` 文件一致）：发布正式版；带 `-` 的标签（如 `v1.0.0-rc1`）仍是预发布版。

## 检查更新

在“设置 → 检查更新”或 Web 后台“系统”页操作，下载后由系统安装器安装，需要用遥控器确认。默认更新范围跟随当前版本：预发布版会收到预发布更新，正式版只收到正式版。

更新从 `api.github.com` 和 GitHub 下载，部分网络环境可能连接失败，此时可手动到 Releases 下载。

## 日志

Web 后台“日志”页可以查看、筛选、下载和清除日志，文件上限约 1MB，重启后仍保留。打开“详细日志”后还会记录按键、请求和轮询耗时。日志不记录访问密码、持仓和备注，但可能包含局域网地址和股票代码。

通过 adb 安装：

```bash
adb install -r androidtv-stock-0.2.0-arm64-v8a-release.apk
```

本 App 是纯 Kotlin 实现，不含原生库，所以 v7、v8 两个包的代码相同，只是按架构分别打包。

## 从源码构建

需要 JDK 17+ 和 Android SDK（`local.properties` 中设置 `sdk.dir` 或设置 `ANDROID_HOME`）。

```bash
./gradlew testDebugUnitTest assembleRelease
```

## 签名说明

未配置私有证书时，使用仓库内的 `signing/sideload.keystore`（密码公开）签名，这样每次构建都可覆盖升级、不丢失配置。这个证书**是公开的，不能证明 APK 的来源**，请只安装本仓库 Actions 构建的 APK。

要使用私有证书，在仓库 Secrets 中配置 `STOCK_KEYSTORE_BASE64`、`STOCK_KEYSTORE_PASSWORD`、`STOCK_KEY_ALIAS`、`STOCK_KEY_PASSWORD`。更换证书后需要先卸载旧版。

## 已知限制

- 节假日判断基于行情日期，没有内置交易日历。
- 提醒只在 App 处于前台时显示；后台时仍会记录，并在回到前台时显示。
- Android 10 及以上系统可能限制开机自动打开界面，此时只有 Web 服务会启动，部分系统连服务也会被限制。
- 只支持沪深北 A 股、指数和场内基金。
